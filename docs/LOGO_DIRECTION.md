# Logo Direction: REFRACT: LOOP

**Game title:** REFRACT: LOOP  
**Style:** Clean. Geometric. Sci‑fi. Light fracture motif.

---

## Core idea

The word **REFRACT** (with optional **: LOOP** for full title) is the logo. Treat it as both type and object: light splitting through a prism. Sharp, precise, no fluff.

---

## Style pillars

| Do | Don’t |
|----|--------|
| Clean, minimal | Cartoon |
| Geometric construction | Rounded fonts |
| Sci‑fi / tech | Organic shapes |
| Light fracture motif | Decorative clutter |
| Sharp cuts, hard edges | Soft gradients everywhere |

---

## Elements

### Sharp cuts

- **Letterforms:** Built from straight segments and clear angles. Think cross-sections, bevels, facets.
- **Fracture:** The word can be “cut” by one or more diagonal or angular breaks (e.g. a slash through “REFRACT” or a split in a letter) to suggest refraction/splitting.
- **Edges:** Crisp. No rounded caps or bubbly outlines.

### Light beams

- **Beams:** Thin, straight lines (rays) that suggest light passing through or out of the word. Can originate from a “core” or cross the letters.
- **Direction:** Prefer clear angles (horizontal, diagonal, 45°) rather than curves.
- **Weight:** Lines thin to medium; they support the word, not overpower it.

### Core glow

- **Focal point:** One area (e.g. the “C”, or the crossing of a fracture) reads as the brightest “core.”
- **Glow:** Soft falloff from that core (gradient or glow) so it feels like a light source, not flat fill.
- **Contrast:** Core bright; rest of word and beams slightly dimmer but still legible.

---

## Typography direction

- **Font style:** Sans-serif, geometric, technical. Monoweight or near-monoweight. Uppercase “REFRACT” works well.
- **Avoid:** Rounded sans, display scripts, heavy serifs, organic or hand-drawn feel.
- **Spacing:** Tight to medium letter-spacing so it reads as one unit; optional slight extra space at the fracture if the word is split.

---

## Color (for reference)

- **Core:** Bright (e.g. white or cool white, or a single accent like cyan/amber if the game has a key hue).
- **Word:** Same as core or one step down; can be the same color with less glow.
- **Beams / fracture lines:** Same palette, lower intensity or thinner so the word stays primary.
- Keep palette minimal (1–2 colors + glow) so it stays clean and sci‑fi.

---

## Composition

- **Lockup (full title):** “REFRACT” as the main element; ": LOOP" optional for full title. No extra tagline required.
- **Fracture:** Optional single clear “break” (e.g. diagonal cut, prism split) that doesn’t hurt readability.
- **Beams:** Optional; if used, they extend from or through the word without crowding it.

---

## Deliverables (for production)

- Primary: **REFRACT** wordmark with fracture + core glow (and optional beams).
- Alternate: Wordmark only (no beams) for small sizes or UI.
- Format: Vector (e.g. SVG) for scale; raster exports for key resolutions (e.g. 256, 512, 1024) with transparency.

---

## One-line brief

**Clean, geometric sci‑fi wordmark “REFRACT” with sharp cuts, a light-fracture motif, thin beam accents, and a single core glow; no cartoon, no rounded or organic shapes.**  
*(Full title: REFRACT: LOOP.)*
