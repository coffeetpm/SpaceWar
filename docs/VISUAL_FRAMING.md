# Visual framing — Commercial sci-fi neon shooter

## Goal

- **First glance:** Readable, marketable — shooter, energy, neon.
- **Deeper play:** Unique — abstract force builds (light / time / space) discovered through play, not through UI labels.

---

## Outer layer (visual language)

All player-facing visuals and copy use **sci-fi energy** framing. No abstract force names (Light / Time / Space) in the main UI or marketing.

| Element | Framing |
|--------|--------|
| **Player** | Sci-fi ship **energy core** — the craft is the reactor; glow, trail, and cockpit read as power source. |
| **Enemies** | **Moving constructs / geometric entities / light-driven machines** — clear silhouettes, defined shapes, energy signatures. Not soldiers, monsters, or war units. |
| **Weapons** | **Energy manifestations** — each loadout is a different reactor signature (photon lance, pulse array, orbital sentinels, etc.). Clean, precise, sculptural. |

Weapon names and upgrade descriptions use energy/loadout language (e.g. “Photon Lance”, “Resonant echo”, “Core overload”) so the game reads as a **neon energy shooter** first.

**Visual emotion:** Calm tension, focused movement, technological art. The game feels like an interactive light installation, not a battlefield. See **docs/INSTALLATION_ART_TONE.md**.

---

## Inner layer (under the hood)

- **Light / Time / Space** remain the upgrade and synergy logic (BuildVocabulary, SynergyManager).
- Force tags and force-pair effects are **not** the main visual language: they drive behaviour and build identity without appearing as primary labels.
- Players discover “this run was a photon–temporal build” through gameplay and optional deeper UI (e.g. run summary resonance line), not through “LIGHT + TIME” in every tooltip.

---

## Market readability

| At first glance | When played deeply |
|-----------------|---------------------|
| Shooter | Build variety (reactor + upgrades) |
| Energy | Energy types / resonance |
| Neon | Abstract force synergies under the hood |

Keep store/steam copy and in-game first-screen text to: **shooter**, **energy**, **neon**. Save “force system” or “resonance builds” for discovery or secondary copy.
